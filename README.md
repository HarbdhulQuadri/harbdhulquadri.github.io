## Architecture

The site uses a zero-build, data-driven static layout powered by vanilla HTML, CSS, and modern client-side JavaScript (`js/main.js`).

Content is decoupled into JSON data stores in the `data/` directory:
- `data/news.json`: Milestones, career updates, and highlights
- `data/publications.json`: Peer-reviewed research papers and abstracts
- `data/teaching.json`: Technical mentorship programs and developer instruction
- `data/service.json`: Community leadership and open-source contributions
- `data/misc.json`: Education, honors, and developer achievements
- `cv/cv.pdf`: Resume / Curriculum Vitae
- `bio/bio.txt`: Plaintext bio
